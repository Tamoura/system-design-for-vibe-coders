# تصميم الأنظمة لمبرمجي الفايب

**تستطيع اليوم أن تبني وتُطلق برمجيات أسرع من أي جيل من المبرمجين قبلك. هذه الدورة تعلّمك ما لن ينبّهك إليه الذكاء الاصطناعي (AI) — حتى يتعطل الإنتاج (production).**

## ما هذه الدورة؟

دورة مكتوبة في تصميم الأنظمة العملي، موجّهة إلى **من يبنون بالذكاء الاصطناعي أولًا**: أولئك الذين يطلقون منتجات حقيقية عبر Claude Code وCursor وأمثالهما، دون دراسة نظامية للأنظمة الموزعة، ثم يصطدمون بالجدار يوم يلتقي نموذجهم الأولي بمستخدمين حقيقيين.

هذه ليست دورة تحضير لمقابلات التوظيف؛ لا سبورة بيضاء ولا «صمّم تويتر». معظم دروسها مبني على **حادثة حقيقية من بيئة الإنتاج** (وبضعة دروس مفاهيمية، مثل 3.1 و6.7، تفتتح بسيناريو مركّب من حوادث عدة، وتقول ذلك صراحة) في منصة فعلية متعددة الواجهات (ويب وiOS وأندرويد وتلفاز، تخدم جمهورًا عالميًا)، بُنيت وتُدار إلى حدّ بعيد *بواسطة* وكلاء ذكاء اصطناعي (AI agents) بإشراف بشري. وتغطي الحوادث كامل ما ينمو إليه المنتج الحقيقي: الكاش (cache) وشبكات توزيع المحتوى (CDNs)، البيانات والنسخ الاحتياطي (backups)، النشر (deploy)، المصادقة (auth) وOAuth، البريد والنشرات البريدية، مفاتيح الميزات (feature flags)، إصدارات الموبايل، الأمن وإساءة الاستخدام، والمراقبة (observability). ندوب الحوادث حقيقية، والإصلاحات وصلت إلى الإنتاج فعلًا.

## كيف تسير الدورة؟

**الوقت:** 69 درسًا، نحو 104 ساعات دراسة في المجموع (التقدير المذكور أعلاه). والوتيرة المعقولة نحو أربعة دروس، أي ست ساعات، في الأسبوع، فتنتهي الدورة في نحو 17 أسبوعًا، أي أربعة أشهر تقريبًا؛ والجزء 0 (الأسس) وحده يستغرق ما يزيد قليلًا على أربع ساعات.

**ما تحتاجه:** حاسوب، ووكيل ذكاء اصطناعي يستطيع تشغيل الأوامر عليه (Claude Code أو Cursor؛ يحتاج Claude Code إلى خطة مدفوعة أو رصيد API، ولـ Cursor خطة مجانية محدودة)، ومن الدرس F.5 حسابان مجانيان على GitHub وعلى استضافة. يبدأ الجزء 0 بصندوق تجهيز مدته 20 دقيقة. ولا تلصق كلمة مرور أو رمز وصول في المحادثة أبدًا.

**لا يُشترط أن تعرف البرمجة.** أنت في هذه الدورة المهندسُ المعماري ومفتشُ السلامة، ووكيلك الذكي هو البنّاء. كل خطوة عملية مكتوبة تعليماتٍ *تعطيها للوكيل (agent)* ودليلًا *تطالبه به* — لا كودًا تكتبه بنفسك. ومن يعرف البرمجة يجد مربعات **🔧 تحت الغطاء** الاختيارية بالأوامر والتفاصيل.

لكل درس الأركان الأربعة نفسها:

1. **🔥 قصة من الميدان** — حادثة حقيقية (أو، في بضعة دروس مفاهيمية، سيناريو مركّب معلَن): الأعراض كما ظهرت، والفرضيات الخاطئة، والسبب الجذري (root cause) الفعلي، والإصلاح الذي وصل إلى الإنتاج.
2. **📐 المبدأ** — مفهوم تصميم الأنظمة الذي تعلّمنا إياه الحادثة، بلغة بسيطة ومخططات، وكل مصطلح يُعرَّف قبل استخدامه (يسنده [المسرد](./GLOSSARY.ar.md)).
3. **🎛️ وجّه وكيلك** — تطبّق المبدأ على **Relay**، منتج عام عن قصد (حسابات، محتوى صنّاع، وسائط، خلاصات، بريد، تطبيق موبايل) يُبنى عبر الدورة من نموذج إلى إنتاج دون انقطاع (zero-downtime) — بأن تقول للوكيل *ماذا* يبني: الموجّهات الحرفية، والسياق (context) الذي يجعله يبني الصواب، وحاجز الأمان (guardrail) الذي يجعل القاعدة تعيش بعد المحادثة. وطبّق كل خطوة على تطبيقك أنت إن كان لك تطبيق.
4. **✅ تحقق منه** — الركن الذي يجعل برمجة الفايب (vibe coding) آمنة: قائمة أدلة تثبت أن الخطوة نجحت فعلًا، مصوغة بحيث لا يتطلب فحصُها **قراءة أي كود** — أشياء تراها وتنقرها أو تجعل الوكيل يعرضها من الطبقة التي يلمسها المستخدمون. وهذا يغطي ما يفعله المنتج على نحو ظاهر. لكنه وحده لا يثبت الأمان، ولا السلامة حين تحدث أشياء في الوقت نفسه، ولا فصل بيانات العملاء بعضها عن بعض، ولا الجاهزية للإنتاج؛ لذلك تقرنه الدورة بفحوص آلية تعمل في كل مرة، وبمراجعة متخصص مستقل للتغييرات عالية الخطورة (مستويات الدليل الثلاثة، المعرَّفة في الدرس 0.1).

## لمن هذه الدورة؟

- تبني (أو تريد أن تبني) منتجات حقيقية بتوجيه وكيل ذكاء اصطناعي — بخلفية برمجية أو بدونها.
- اكتويتَ (أو توشك أن تكتوي) بشيء «كان يعمل» حتى وصل المستخدمون الحقيقيون.
- تريد أن تكفّ عن الثقة وتبدأ التحقق — دون حاجة إلى قراءة الكود.

**جديد كليًا على هذا العالم؟** ابدأ من **الجزء 0 — الأسس**: خمسة دروس بلغة بسيطة بلا أي شروط مسبقة (ما الخادم (server)، وماذا يحدث حين تفتح موقعًا، وما الكود والمستودع (repo) والنشر، وكيف تعمل مع وكيلك، ووضع صفحتك الأولى على الهواء — بدليل).

## وليست لِـ

- المتأهبين للمقابلات — لذلك دوراتها.
- من يريد نظرية بلا تشغيل حقيقي.

## اللغات

الدورة **ثنائية اللغة**: كل وثيقة تصدر بالإنجليزية والعربية (بتخطيط RTL). الملفات الإنجليزية هي مصدر الحقيقة (source of truth) أثناء الصياغة، والعربية مرآتها إلى جوارها (`README.ar.md`، `OUTLINE.ar.md`، `lesson-N.ar.md`).

## كيف تقرؤها

تُبنى الدورة كاملةً في عدة صيغ مكتفية بذاتها. اقرأها على الإنترنت من
**[tamoura.github.io/system-design-for-vibe-coders](https://tamoura.github.io/system-design-for-vibe-coders/)**،
أو خذها معك:

| الصيغة | الملف | لماذا |
|---|---|---|
| صفحة بلغتين | [`index.html`](./index.html) | كل شيء، مع مبدّل لغة |
| صفحة إنجليزية | [`index.en.html`](./index.en.html) | لغة واحدة، بنصف الحجم |
| صفحة عربية | [`index.ar.html`](./index.ar.html) | لغة واحدة، RTL بالكامل |
| PDF | `course-ar.pdf` · `course-en.pdf` | الطباعة والقراءة دون اتصال (نحو 350 صفحة) |
| EPUB | `course-ar.epub` · `course-en.epub` | القرّاء الإلكترونيون وKindle |

كل صيغة تحمل الدروس الثمانية والستين بمخططاتها مرسومةً مسبقًا — بلا خادم ولا اتصال ولا CDN.
وصفحات HTML تضيف خريطة دورة قابلة للنقر، وملحق المسرد، ووضعًا داكنًا. أما PDF وEPUB فتُنشر مع
كل إصدار بدل أن تُودَع في المستودع؛ ولبنائها محليًا استخدم `npm run dist`.

```
npm install     # مرة واحدة — marked وmermaid وpuppeteer وarchiver (للبناء فقط)
npm run build   # إعادة توليد صفحات HTML من الماركداون
npm run dist    # ما سبق، إضافةً إلى PDF وEPUB لكل لغة في dist/
npm run check   # يفشل إن كانت الصفحات المودعة قديمة (يستخدمه التكامل المستمر)
```

يقارن `check` بصمةً للمصادر — الدروس وجداول README والمسارد وقوالب البناء نفسها — بالبصمة
المضمّنة في كل صفحة مودعة. وهو لا يقارن البايتات المولَّدة عن قصد: إذ يقيس Mermaid النصّ ليحدّد
أحجام الصناديق، فيخرج المدخل نفسه بهندسة SVG مختلفة على جهاز بخطوط مختلفة. أما البصمة فتجيب عن
السؤال الذي يهم فعلًا («هل بُنيت هذه الصفحة من هذا الماركداون؟») في نصف ثانية، وبلا متصفح.

**ملفات الماركداون في `modules/` هي مصدر الحقيقة.** وكل ما سبق ناتجٌ مولَّد — لا تحرّره يدويًا
أبدًا، بل حرّر الدرس ثم أعد البناء. ويفشل البناء صراحةً إن اختلف عدد الدروس الإنجليزية عن
العربية في أي وحدة، أو تعذّر رسم أي مخطط، أو لم يكن أحد مستندات EPUB صحيح البنية.
