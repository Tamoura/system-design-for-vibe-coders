# تصميم الأنظمة لمبرمجي الفايب (System Design for Vibe Coders)

**تستطيع اليوم أن تبني وتُطلق برمجيات أسرع من أي جيل من المبرمجين قبلك. هذه الدورة تعلّمك ما لن ينبّهك إليه الذكاء الاصطناعي — حتى يتعطل الإنتاج.**

## ما هذه الدورة؟

دورة مكتوبة في تصميم الأنظمة العملي، موجّهة إلى **من يبنون بالذكاء الاصطناعي أولًا**: أولئك الذين يطلقون منتجات حقيقية عبر Claude Code وCursor وأمثالهما، دون دراسة نظامية للأنظمة الموزعة، ثم يصطدمون بالجدار يوم يلتقي نموذجهم الأولي بمستخدمين حقيقيين.

هذه ليست دورة تحضير لمقابلات التوظيف؛ لا سبورة بيضاء ولا «صمّم تويتر». كل درس فيها مبني على **حادثة حقيقية من بيئة الإنتاج** في منصة فعلية متعددة الواجهات (ويب وiOS وأندرويد وتلفاز، تخدم جمهورًا عالميًا)، بُنيت وتُدار إلى حدّ بعيد *بواسطة* وكلاء ذكاء اصطناعي بإشراف بشري. وتغطي الحوادث كامل ما ينمو إليه المنتج الحقيقي: الكاش وشبكات توزيع المحتوى، البيانات والنسخ الاحتياطي، النشر، المصادقة وOAuth، البريد والنشرات البريدية، مفاتيح الميزات، إصدارات الموبايل، الأمن وإساءة الاستخدام، والمراقبة. الندوب حقيقية، والإصلاحات وصلت إلى الإنتاج فعلًا.

## كيف تسير الدورة؟

**لا يُشترط أن تعرف البرمجة.** أنت في هذه الدورة المهندسُ المعماري ومفتشُ السلامة، ووكيلك الذكي هو البنّاء. كل خطوة عملية مكتوبة تعليماتٍ *تعطيها للوكيل* ودليلًا *تطالبه به* — لا كودًا تكتبه بنفسك. ومن يعرف البرمجة يجد مربعات **🔧 تحت الغطاء** الاختيارية بالأوامر والتفاصيل.

لكل درس الأركان الأربعة نفسها:

1. **🔥 قصة من الميدان** — حادثة حقيقية: الأعراض كما ظهرت، والفرضيات الخاطئة، والسبب الجذري الفعلي، والإصلاح الذي وصل إلى الإنتاج.
2. **📐 المبدأ** — مفهوم تصميم الأنظمة الذي تعلّمنا إياه الحادثة، بلغة بسيطة ومخططات، وكل مصطلح يُعرَّف قبل استخدامه (يسنده [المسرد](./GLOSSARY.ar.md)).
3. **🎛️ وجّه وكيلك** — تطبّق المبدأ على **Relay**، منتج عام عن قصد (حسابات، محتوى صنّاع، وسائط، خلاصات، بريد، تطبيق موبايل) يُبنى عبر الدورة من نموذج إلى إنتاج دون انقطاع — بأن تقول للوكيل *ماذا* يبني: الموجّهات الحرفية، والسياق الذي يجعله يبني الصواب، وحاجز الأمان الذي يجعل القاعدة تعيش بعد المحادثة. وطبّق كل خطوة على تطبيقك أنت إن كان لك تطبيق.
4. **✅ تحقق منه** — الركن الذي يجعل برمجة الفايب آمنة: قائمة أدلة تثبت أن الخطوة نجحت فعلًا، مصوغة بحيث لا يتطلب فحصُها **قراءة أي كود** — أشياء تراها وتنقرها أو تجعل الوكيل يعرضها من الطبقة التي يلمسها المستخدمون.

## لمن هذه الدورة؟

- تبني (أو تريد أن تبني) منتجات حقيقية بتوجيه وكيل ذكاء اصطناعي — بخلفية برمجية أو بدونها.
- اكتويتَ (أو توشك أن تكتوي) بشيء «كان يعمل» حتى وصل المستخدمون الحقيقيون.
- تريد أن تكفّ عن الثقة وتبدأ التحقق — دون حاجة إلى قراءة الكود.

**جديد كليًا على هذا العالم؟** ابدأ من **الجزء 0 — الأسس**: خمسة دروس بلغة بسيطة بلا أي شروط مسبقة (ما الخادم، وماذا يحدث حين تفتح موقعًا، وما الكود والمستودع والنشر، وكيف تعمل مع وكيلك، ووضع صفحتك الأولى على الهواء — بدليل).

## وليست لِـ

- المتأهبين للمقابلات — لذلك دوراتها.
- من يريد نظرية بلا تشغيل حقيقي.

## اللغات

الدورة **ثنائية اللغة**: كل وثيقة تصدر بالإنجليزية والعربية (بتخطيط RTL). الملفات الإنجليزية هي مصدر الحقيقة أثناء الصياغة، والعربية مرآتها إلى جوارها (`README.ar.md`، `OUTLINE.ar.md`، `lesson-N.ar.md`).

## كيف تقرؤها

تُبنى الدورة كاملةً في عدة صيغ مكتفية بذاتها. اقرأها على الإنترنت من
**[tamoura.github.io/system-design-for-vibe-coders](https://tamoura.github.io/system-design-for-vibe-coders/)**،
أو خذها معك:

| الصيغة | الملف | لماذا |
|---|---|---|
| صفحة بلغتين | [`index.html`](./index.html) | كل شيء، مع مبدّل لغة |
| صفحة إنجليزية | [`index.en.html`](./index.en.html) | لغة واحدة، بنصف الحجم |
| صفحة عربية | [`index.ar.html`](./index.ar.html) | لغة واحدة، RTL بالكامل |
| PDF | `course-ar.pdf` · `course-en.pdf` | الطباعة والقراءة دون اتصال (نحو 350 صفحة) |
| EPUB | `course-ar.epub` · `course-en.epub` | القرّاء الإلكترونيون وKindle |

كل صيغة تحمل الدروس الثمانية والستين بمخططاتها مرسومةً مسبقًا — بلا خادم ولا اتصال ولا CDN.
وصفحات HTML تضيف خريطة دورة قابلة للنقر، وملحق المسرد، ووضعًا داكنًا. أما PDF وEPUB فتُنشر مع
كل إصدار بدل أن تُودَع في المستودع؛ ولبنائها محليًا استخدم `npm run dist`.

```
npm install     # مرة واحدة — marked وmermaid وpuppeteer وarchiver (للبناء فقط)
npm run build   # إعادة توليد صفحات HTML من الماركداون
npm run dist    # ما سبق، إضافةً إلى PDF وEPUB لكل لغة في dist/
npm run check   # يفشل إن كانت الصفحات المودعة قديمة (يستخدمه التكامل المستمر)
```

**ملفات الماركداون في `modules/` هي مصدر الحقيقة.** وكل ما سبق ناتجٌ مولَّد — لا تحرّره يدويًا
أبدًا، بل حرّر الدرس ثم أعد البناء. ويفشل البناء صراحةً إن اختلف عدد الدروس الإنجليزية عن
العربية في أي وحدة، أو تعذّر رسم أي مخطط، أو لم يكن أحد مستندات EPUB صحيح البنية.
