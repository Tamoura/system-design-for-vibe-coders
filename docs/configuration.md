# Configuration

Generated by `npm run env:docs` from `src/lib/env.ts`: do not edit by hand. Every variable is read from
the environment (twelve-factor, lesson 7.4) and checked when the web app, the worker or the migrations start;
a missing or malformed one stops the process with a message that names it. "Required" also depends on the
rules at the bottom of the schema: `BETTER_AUTH_SECRET` in production, the `S3_*` values with
`STORAGE_DRIVER=s3`, the Stripe values together.

| `APP_ENV` | no |  | `development`, `preview`, `staging`, `production` | Which environment this is (lesson 7.4). Tags logs, traces and errors; `production` refuses development-only settings. |
| `APP_URL` | no | `http://localhost:3000` |  | The public URL of the app, used in emails and redirects. https:// makes cookies Secure. |
| `APP_RELEASE` | no |  |  | The release: the git SHA the image was built from (set by the Dockerfile). Tags errors and traces. |
| `DATABASE_URL` | yes |  |  | Required. Postgres 16 connection string (lesson 2.1). The worker and migrations use it too. |
| `BETTER_AUTH_SECRET` | no |  |  | Required in production. Signs session cookies and tokens (lesson 1.1). |
| `GITHUB_CLIENT_ID` | no |  |  | Optional: "Sign in with GitHub" (with GITHUB_CLIENT_SECRET). |
