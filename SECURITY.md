# Security

## Report a security problem

Use GitHub's private vulnerability reporting for this repository:
https://github.com/Tamoura/system-design-for-vibe-coders/security/advisories/new

Please do not open a public issue for a security problem. Describe what you found, where, and how to reproduce it.

## What this repository is

The courses are educational. Some lab examples are deliberately insecure so that learners can find and fix the faults. A weakness in a lab example that the lesson already describes is not a vulnerability. A problem in the site pages, the build scripts or the workflows is.

For a mistake in course content that is not a security problem, use the issue form described in `CONTRIBUTING.md`.
