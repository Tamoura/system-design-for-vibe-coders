How these courses are made

A short, plain account of how this library is written, what has not been checked yet, and how to tell us about a mistake.

Status of every course: drafted with AI, not yet expert-reviewed.

What this is

A free library of 12 courses in English and Arabic, with 379 lessons in all. The courses were written between July and October 2026.

How they are made

  • The owner sets the scope and the rules for each course.
  • AI agents (Claude Code) draft the lessons, check facts using web search, write the quizzes, translate the lessons into Arabic, and check that the Arabic has the same structure as the English.
  • Fact checks often rely on search summaries rather than the full source.
  • The pages are built from Markdown files in a public repository on GitHub.

What has not been done yet

  • No lesson has been reviewed by a named subject expert.
  • No Arabic editor has reviewed the Arabic text.
  • No group of learners has piloted a course.
  • No certificate is issued.

Known issues being fixed

  • The AI governance course is being re-checked against changes to EU AI law.
  • Several practice exams are under revision, because the correct option can often be spotted by its length.
  • The course on running AI agents in production is being renamed, and its regulatory section has been removed.

How to report a problem

Course pages have a “Report a problem” link at the bottom. It opens a new issue on GitHub, so you need a GitHub account. You can also report a problem here.
