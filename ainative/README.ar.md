## ما هذه الدورة

لدى كل مهندس تقريبًا اليوم وكيل ذكاء اصطناعي (AI agent) يستطيع قراءة مستودع وتعديل الملفات وتشغيل الأوامر وفتح طلب دمج (pull request). استخدامه سهل، أما استخدامه *جيدًا* فمهارة: المهندسون الذين يستفيدون أكثر من الوكلاء ليسوا الذين يكتبون أقل، بل الذين يعطون السياق الصحيح، ويكتبون ما معنى «انتهى»، ويعملون بخطوات صغيرة مُتحقَّق منها، ويلاحظون متى تكون الإجابة الواثقة خاطئة.

تدرّس هذه الدورة المهارة بالممارسة. تنضم إلى فريق **منصة المدفوعات** في **بنك نجم** (بنك خيالي تستخدمه مكتبة الدورات كلها) وتعمل على قاعدة شيفرة واحدة هي **نجم ريميت** أربعة عشر أسبوعًا: التعرّف على شيفرة غير مألوفة، وإطلاق ميزات، ومراجعة طلب دمج كتبه وكيل، وإصلاح خطأ في الإنتاج من سجلاته، وترويض الشيفرة الموروثة (legacy code)، وتحصين إعدادك، وأتمتة وكيلك بالخطافات (hooks) والمهارات والوكلاء الفرعيين (subagents)، وتشغيل الوكلاء بالتوازي، وكتابة الدليل العملي لفريقك.

لا تحتاج إلى مفتاح API لتنفيذ المختبرات. عدّة المختبر، واسمها `ailab`، تبدأ كل مهمة، وتصحّح اختباراتها الخفية (hidden tests) وفحوصاتها نتيجتك دون اتصال. استخدم **Claude Code** (المثال التطبيقي في الدورة) أو أي أداة وكيلية أخرى أو لا وكيل إطلاقًا: المُقيِّم لا يرى إلا العمل. وأدوات الوكلاء غالبًا مدفوعة: وقت كتابة هذا (نوفمبر 2026) يحتاج Claude Code إلى خطة مدفوعة أو إلى فوترة API بحسب الاستخدام، لا إلى خطة Claude المجانية، فراجع الأسعار الحالية أولًا. أما مسار العمل بلا وكيل فلا يكلّف شيئًا.

## العادات الخمس

1. **السياق أولًا.** قل للوكيل ما يحتاج إلى معرفته قبل أن تقول له ماذا يفعل.
2. **حدِّد قبل أن تفوِّض.** اكتب ما معنى «انتهى»، ثم خطِّط.
3. **خطوات صغيرة مُتحقَّق منها.** تحقّق بعد كل خطوة، وأوقف الوكيل مبكرًا لا متأخرًا.
4. **ثق بالدليل لا بالطلاقة.** الاختبارات وإعادة الإنتاج والفروقات (diffs) والسجلات أدلة. أما الفقرة الواثقة فليست دليلًا.
5. **أتمت الحلقة وحافظ على المهارة.** حوّل الخطوات المتكررة إلى أوامر وخطافات، وواصل ممارسة الأساسيات لتعرف متى يخطئ الوكيل.

الحلقة هي **حدِّد ← فوِّض ← تحقّق ← ادمج**، والسياق يغذّي كل خطوة والأمان يحيط بها كلها.

## كيف يعمل كل درس

لكل درس الأجزاء العشرة نفسها:

| الجزء | ما تحصل عليه |
|---|---|
| ⚡ **الدرس في دقيقة** | الدرس في نقاط قليلة: ما هو، والقاعدة الأهم، وإشارة القرار، وأكبر فخ. |
| 🧭 **لماذا يهم** | موقف في بنك نجم، أو إخفاق عام موثَّق جيدًا، يجعل الموضوع لا مفرّ منه. |
| 📐 **كيف يعمل** | الأفكار تصعد سلّمًا: 🟢 *الأساسيات* ← 🟡 *التعمق أكثر* ← 🔴 *نظرة الخبير*. |
| 🧰 **الأدوات** | الأدوات والممارسات والأنماط المناسبة: ما تفعله كل منها ومتى تلجأ إليها. |
| 🏛️ **عمليًا في بنك نجم** | المُخرَج الذي ينتجه الدرس؛ وفي المختبرات: التذكرة وكيفية البدء وطريقة التقييم والمُخرَج الأسبوعي والجلسة الجماعية. |
| 🛠️ **التمارين** | ثلاثة تمارين متدرجة (🟢 🟡 🔴)، لكل منها معيار «يكتمل عندما» وملاحظة هل يحتاج إلى وكيل. |
| ⚠️ **أخطاء وفخاخ** | ما يسوء في الممارسة، وما تفعله بدلًا منه. |
| 🧾 **الخلاصة** | الخلاصات التي تستحق التذكّر. |
| ✍️ **اختبر نفسك** | خمسة أسئلة معظمها سيناريوهات، بإجابات مخفية وشروح. |
| 📚 **المراجع** | التوثيق الرسمي والمصادر الأولية؛ وتضيف دروس المفاهيم قائمة قصيرة «تعمّق أكثر». |

كل درس موسوم بـ**تركيزه**: العقلية أو السياق أو سير العمل أو التحقق أو الأمان أو الأتمتة أو الفريق. ويجمع [دليل الأدوات](./TOOLKIT.ar.md) كل أداة ونمط في مكان واحد.

## عدّة المختبر: نجم ريميت و`ailab`

**نجم ريميت** خدمة Python صغيرة (الرسوم، وعروض أسعار الصرف، والحدود، والفحص، ودفتر أستاذ موروث، وإشعارات بالإنجليزية والعربية) مع مكتبة مساعدة داخلية هي `najmkit` لم يرها أي نموذج ذكاء اصطناعي من قبل. تجد العدّة في `ainative/ailab/` داخل مستودع الدورة:

```text
python -m ailab list                       # the labs
python -m ailab start m04 --dir ~/ainative/m04   # a repository with the task, ready to work in
python -m ailab grade m04 --dir ~/ainative/m04   # hidden tests and checks, offline
```

كل مختبر يذكر هل يحتاج إلى وكيل، ويقدّم مسارًا بدونه. وتُفحص المختبرات باختبارات العدّة نفسها: يبدأ كل منها فاشلًا، ويجعله حلٌّ مرجعي ناجحًا.

## المسار

| المرحلة | الوحدات | ستكون قادرًا على… |
|---|---|---|
| 🟢 **الأساسيات** | 0–3 | أن تشرح ما الذي يفعله المهندس الأصيل في الذكاء الاصطناعي بصورة مختلفة، وكيف يعمل وكلاء البرمجة ويخفقون فعلًا، وأن تعطي الوكيل السياق الصحيح، وتحوّل تذكرة غامضة إلى مواصفة يستطيع الوكيل البناء منها. |
| 🟡 **الممارس** | 4–9 و11 | أن تدير الحلقة اليومية، وتتحقق من الشيفرة التي يكتبها الذكاء الاصطناعي وتراجعها، وتصحّح الأخطاء وتتعرّف على شيفرة غير مألوفة، وتغيّر الشيفرة الموروثة بأمان، وتؤمّن إعدادك، وتؤتمت وكيلك بالخطافات والمهارات والوكلاء الفرعيين والنصوص غير التفاعلية. |
| 🔴 **المحترف** | 10 و12–14 | أن تشغّل الوكلاء بالتوازي، وتضع ممارسة الفريق ومقاييسه، وتحافظ على حدّة مهارتك، وتصل بتغيير كامل عبر الدورة كلها. |

**كم تستغرق.** كل وحدة أسبوع واحد. خطِّط لخمس إلى ثماني ساعات في الأسبوع إجمالًا: القراءة، ومن 3 إلى 5 ساعات للتمارين والمختبر (والمختبر هو الجزء الأكبر؛ فالمختبر 5.2 مثلًا يستغرق نحو ثلاث ساعات)، والجلسة الجماعية ومدتها 60 دقيقة. وتشمل الوحدة 0 الإعداد، فأضف ساعة. أما أسبوع المشروع الختامي فاستثناء: من 8 إلى 12 ساعة من العمل التطبيقي، إضافة إلى عرض مدته 90 دقيقة، فامنحه أسبوعًا أو اثنين. وترويسة كل درس تعطي تقديره الخاص؛ وفي المشروع الختامي تُضاف ساعات العمل التطبيقي المذكورة أعلاه إليه.

**إن كنت تدرس وحدك.** تفترض الجلسات الجماعية وجود مجموعة دراسة، لكنها ليست شرطًا. وحدك، نفّذ خطوات كل جلسة كتابةً في مستودع ملاحظاتك: وحيث تقول «تبادل مع زميل»، ضع عملك جانبًا يومًا ثم راجعه بعين باردة، أو اطلب من جلسة وكيل جديدة أن تراجعه مقابل قائمة التحقق في الدرس، وقرّر أي ملاحظاتها تقبل. وفي عرض المشروع الختامي، سجّل نفسك وأنت تجيب عن أسئلته، واعرض التسجيل على زميل متى استطعت: فجلسة الوكيل لا تغني عن أسئلته.

## الدورات المرافقة

*بناء تطبيقات الذكاء الاصطناعي والوكلاء* (إن كنت تبني منتجات ذكاء اصطناعي لا تعمل بأدواته)، و*اختبار البرمجيات من الصفر إلى الاحتراف في عصر الذكاء الاصطناعي*، و*الذكاء الاصطناعي الآمن وأمان التطبيقات*، و*تشغيل وكلاء الذكاء الاصطناعي في الإنتاج*، و*تصميم الأنظمة لمبرمجي الـvibe*، و*السحابة وDevOps*، و*حوكمة الذكاء الاصطناعي*، و*إدارة منتجات الذكاء الاصطناعي*، و*من التخرّج إلى التوظيف*.

## لغتان

كل درس متاح بالإنجليزية والعربية. وفي النسخة العربية يحمل كل مصطلح تقني اسمه الإنجليزي بين قوسين، مثل «هندسة السياق (context engineering)»، لأن الأدوات والتوثيق وإعلانات الوظائف التي ستعمل معها بالإنجليزية.
